深入理解 LINUX 内核

Understanding the Linux Kernel — 第三版 · 知识脑图

Daniel P. Bovet · Marco Cesati 著 / 陈莉君 · 张琼声 · 张宏伟 译

本书以 Linux 2.6 为蓝本，自底向上系统讲述 Linux 内核的内部工作机理：从内存寻址、进程管理、调度，到中断与同步、虚拟文件系统、设备驱动、Ext2/Ext3、进程通信、程序执行与系统启动。整体强调'内核如何为不同请求提供服务'这一核心主线。
