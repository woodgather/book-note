前言 · 关于这本书

本章目标：了解 Kotlin 的诞生背景、为什么值得学、适合谁读以及如何使用本书

★为什么学 Kotlin

  • 2011 年 JetBrains 启动 Kotlin 开发，2017 年获 Google 官方支持用于 Android
  • 语法简洁、具备现代高级语言特性、与 Java 遗留代码无缝互操作
  • 已被 Google、Uber、Netflix、Capital One、Amazon 等公司采用
  • 跨平台通用：JVM、Android、macOS、Windows、JavaScript、原生应用皆可

★本书读者对象

  • 有经验的 Android 开发者，需要 Java 之外的现代特性
  • 对 Kotlin 感兴趣的后端开发者
  • 想学一门高性能编译型语言的新手
  • 已掌握 Java 想了解 Kotlin 的开发者

★如何使用本书

  • 不是参考指南，而是循序渐进的学习教程
  • 建议边读边输入测试代码示例，形成肌肉记忆
  • 每章基于上一章编排，不建议跳读
  • 先介绍变量、集合，再学面向对象、函数式编程
  • 每章包含 深入学习 与 挑战练习，先掌握主线再深入
🔗 官方文档：kotlinlang.org/docs/reference — 遇到新知识点随时查阅并动手实践
第 1 章

Kotlin 应用开发初体验

本章目标：安装 IntelliJ IDEA · 创建第一个 Kotlin/JVM 项目 · 编写运行 Kotlin 代码 · 熟悉 REPL

1.1安装 IntelliJ IDEA

  • IntelliJ IDEA 是 JetBrains 公司打造的 Kotlin 集成开发环境
  • 下载社区开发版：jetbrains.com/idea/download
  • 内建工具支持：编写、运行、调试、检查、重构一体化

1.2第一个 Kotlin 项目

  • 创建项目时选择 Kotlin → Kotlin/JVM — 告诉 IntelliJ 用 Kotlin 编写运行在 JVM 上的代码
  • 项目名 Sandbox，关联 JDK 8，项目根目录为项目文件夹
  • 在 src 文件夹新建 Kotlin File/Class，例如 Hello.kt
1.2.1 创建首个 Kotlin 文件 main 入口
// 应用程序入口函数 fun main(args: Array<String>) { println("Hello, World!") }
1.2.2 运行 Kotlin 文件
  • 输入 main 按 Tab 键，IntelliJ 自动补全函数结构
  • 右击编辑区 → Run，或使用工具栏绿色三角
  • 底部 Run 窗口显示输出结果

1.3Kotlin REPL

  • REPL = Read-Eval-Print Loop（读取-执行-打印-循环）
  • Tools → Kotlin → Kotlin REPL，无须创建文件即可快速测试代码片段
  • 非常适合验证语法、试验 API

1.4深入学习：为什么用 IntelliJ

  • JetBrains 既是 Kotlin 的创造者也是 IntelliJ 的开发方，工具与语言深度协同
  • 代码补全、智能提示、重构、调试能力一流

1.5深入学习：面向 JVM

  • Kotlin 编译产物是 Java 字节码（.class），运行在 JVM 上
  • 因此 Kotlin 可直接调用 Java 类库，Java 也可调用 Kotlin
  • 面向 JVM 的语言还包括 Java、Scala、Groovy 等

1.6挑战练习

🎯 在 REPL 中研究 Kotlin 的算术运算符：+ - * / %，并尝试整数除法与小数除法的差异
第 2 章

变量、常量和类型

本章目标：掌握 Kotlin 基本数据类型 · 声明 var/val · 理解类型推断与编译时常量

2.1数据类型

  • 类型描述常量或变量中保存的数据
  • 告诉编译器如何进行类型检查（type checking）
  • 类型检查能避免类型不匹配赋值，是 Kotlin 的重要特色

2.2声明变量 var

// 玩家经验值，可变 var experiencePoints: Int = 5 experiencePoints = 10 // var 可重新赋值
  • var 关键字声明可变变量
  • 声明格式：var 变量名: 类型 = 初值

2.3Kotlin 的内置数据类型

Int / Long
整数，默认 Int 32 位；Long 64 位，加 L 后缀
Double / Float
小数，Double 64 位默认；Float 加 f 后缀
Boolean
true / false 布尔值
Char
单字符，用单引号 'a'
String
字符串，双引号包裹

2.4只读变量 val

val name: String = "Madrigal" // name = "Ario" ❌ 编译错误：val 不可重新赋值
  • val = value，只读，初始化后不可重新赋值
  • 优先使用 val，只在确实需要变化时才用 var

2.5类型推断

val name = "Madrigal" // 推断为 String val healthPoints = 89 // 推断为 Int val isBlessed = true // 推断为 Boolean
  • 声明变量时可省略类型，编译器根据初始值自动推断
  • 推断后类型不可更改

2.6编译时常量 const val

const val MAX_EXPERIENCE: Int = 5000
  • const val 用于编译期就已知且不会改变的值
  • 只能修饰 val，且只能用于顶层或 object 成员
  • 必须是基本类型或 String
⚠️ val vs const val：val 是运行时常量（只读），const val 才是编译时常量

2.7查看 Kotlin 字节码

  • Tools → Kotlin → Show Kotlin Bytecode，可以看到 Kotlin 编译后的字节码
  • 点击 Decompile 还能反编译为等效 Java 代码，加深理解

2.8深入学习：Kotlin 中的 Java 基本数据类型

  • Kotlin 的 Int 在 JVM 上映射为 Java 的 int 原生类型
  • Kotlin 没有"基本数据类型 vs 包装类型"的区分，Int? 等才是 Java 的包装类型

第 3 章

条件语句

本章目标：掌握 if/else、when 表达式、range 区间、string 模板 · 引入贯穿项目 NyetHack

3.1if / else 语句

if (healthPoints == 100) { println("状况极佳") } else { println("有受伤") }
3.1.1 添加更多条件
  • 用 else if 分支处理多种情况
  • 条件必须是 Boolean 表达式
3.1.2 if/else 嵌套语句
  • if 内部可嵌套另一个 if，但层级过深会降低可读性
3.1.3 更优雅的条件语句
  • Kotlin 中 if 也是表达式，可以赋值给变量
  • 表达式形式更简洁：val status = if (hp == 100) "极佳" else "受伤"

3.2range 区间

val health = 85 if (health in 1..100) { println("有效健康值") } if (health !in 0..0) println("活着")
  • 1..10 表示闭区间 [1, 10]
  • 1 until 10 表示半开区间 [1, 10)
  • 使用 in / !in 判断是否在区间内

3.3when 表达式

val mood = when { healthPoints == 100 -> "极佳" healthPoints in 90..99 -> "良好" healthPoints in 75..89 -> if (isBlessed) "受祝福" else "尚可" else -> "危险" }
  • when 是 Kotlin 的多分支表达式，比 switch 强大
  • 支持任意表达式作为分支条件
  • 类似 if，when 也是表达式可赋值
  • 无匹配时执行 else 分支

3.4string 模板

val name = "Madrigal" val hp = 89 println("玩家 $name 当前血量 $hp") println("是否为受祝福: ${isBlessed}") println("光环颜色: ${auraColor(isBlessed, hp, isImmortal)}")
  • 用 $变量名 嵌入变量
  • 用 ${表达式} 嵌入复杂表达式
  • 字符串里要使用 $ 字面量需转义：\$

3.5挑战练习

🎯 range 研究：探索 1..10 / 1 until 10 / 10 downTo 1 / 1..10 step 2
🎯 优化玩家光环展示
🎯 可配置的玩家状况报告格式（使用 string 模板 + when）
第 4 章

函数

本章目标：理解函数结构 · 重构 NyetHack · 自定义函数 · 默认参数 / 具名参数 / 单表达式函数

4.1使用函数重构代码

  • 用函数封装 NyetHack 中的部分逻辑
  • 为后续添加 Fireball 魔法等新功能打基础

4.2函数结构剖析

fun auraColor(isBlessed: Boolean, healthPoints: Int, isImmortal: Boolean): String { val auraVisible = isBlessed && healthPoints > 50 || isImmortal return if (auraVisible) "绿色" else "无" }
4.2.1 函数头
  • 格式：fun 函数名(参数列表): 返回类型
  • fun = function 关键字
4.2.2 函数体
  • 用 { } 包裹函数体
  • 使用 return 返回值；无返回值时使用 Unit 或省略
4.2.3 函数作用域
  • 顶层函数默认 public
  • 文件私有用 private

4.3调用函数

  • 使用 函数名(参数) 调用
  • 传参按位置匹配；可使用具名参数改变顺序

4.4以函数重构代码

fun formatHealthStatus(healthPoints: Int, isBlessed: Boolean) = when (healthPoints) { 100 -> "极佳" in 90..99 -> "良好" in 75..89 -> if (isBlessed) "受祝福" else "尚可" else -> "危险" }

4.5自定义函数 — Fireball

fun castFireball(numFireballs: Int = 2) = println("一团火球凭空出现 (x$numFireballs)")

4.6默认值参

  • 参数后可使用 = 默认值 指定默认值
  • 调用时可省略该参数，简化调用

4.7单表达式函数

  • 函数体只有单个表达式时，可使用 = 简写，省略花括号和 return
  • 编译器可自动推断返回类型

4.8Unit 函数

  • Unit 相当于 Java 的 void，表示无返回值
  • Kotlin 中 Unit 默认可省略

4.9具名函数参数

castFireball(numFireballs = 3) printPlayerStatus(auraColor = "红", name = "Madrigal", healthStatus = ..., isBlessed = ...)
  • 调用时用 参数名 = 值，可任意顺序
  • 提高可读性，避免布尔/同型参数误传

4.10深入学习

  • Nothing 类型：函数永远不会正常返回（如 throw、无限循环）
  • Java 中的文件级函数：编译为对应类中的 static 方法
  • 函数重载：同名函数参数不同
  • 反引号中的函数名：用 `` ` `` 包裹可使用任意名字（含空格/关键字）

第 5 章

匿名函数与函数类型

本章目标：掌握 lambda 表达式 · 函数类型 · it 关键字 · 内联函数 · 函数引用

5.1匿名函数

// 匿名函数：没有名字的函数 val greet = fun(name: String): String = "Hi, $name!" println(greet("Madrigal"))
  • 匿名函数也称 lambda，是定义时不取名字的函数
  • 通常作为值传递给其他函数

5.2函数类型

// (参数类型) -> 返回类型 val myFunc: (String) -> String = { name -> "Hi, $name" }
  • 函数也是一种类型：(参数) -> 返回值
  • 可作为变量类型、参数类型、返回类型

5.3lambda 关键字 — it

val greet: (String) -> String = { it.uppercase() } // 只有一个参数时可省略 ->，用 it 指代

5.4类型推断

  • lambda 形参类型可省略（从上下文推断）

5.5函数参数 / 简略语法

// 完整 val list = listOf(1, 2, 3) val doubled = list.map { n: Int -> n * 2 } // 简略（带 it） val doubled2 = list.map { it * 2 }
  • 参数是函数的函数叫高阶函数

5.6函数内联 inline

  • inline 关键字修饰函数：将函数体在调用处展开
  • 减少 lambda 对象分配，提升性能
  • 适合与 lambda 配合的高阶函数

5.7函数引用 ::

fun double(x: Int) = x * 2 val list = listOf(1, 2, 3) val doubled = list.map(::double) // 函数引用
  • ::函数名 引用已定义的具名函数作为函数类型值

5.8函数类型作为返回类型

fun getGreetingFunction(): (String) -> String { return { name -> "Hello, $name!" } }

5.9深入学习

  • lambda 是闭包：可捕获外部变量
  • lambda 与匿名内部类的区别：更轻量、可捕获、自动转换 SAM
第 6 章

null 安全与异常

本章目标：理解 Kotlin null 安全机制 · 处理可空类型 · 抛出/捕获异常 · 使用先决条件函数

6.1可空性

  • Kotlin 区分可空（nullable）与不可空（non-nullable）类型
  • 默认类型不可为空，需要可空必须显式声明

6.2Kotlin 的 null 类型

var s1: String = "hi" // 不可空 var s2: String? = "hi" // 可空 s2 = null // 合法
  • 类型后加 ? 即可为可空

6.3编译时间与运行时间

  • Kotlin 把大量运行期的 NullPointerException 风险前移到编译期

6.4null 安全

6.4.1 选项一：安全调用操作符 ?.
val len = s2?.length // s2 为 null 时整个表达式返回 null
6.4.2 选项二：!!. 操作符
val len = s2!!.length // 断言非空，否则抛 NPE
6.4.3 选项三：使用 if 判断 null
val len = if (s2 != null) s2.length else 0

6.5异常

6.5.1 抛出异常
throw IllegalStateException("客栈已满")
6.5.2 自定义异常
  • 继承 Exception（已检查）或 RuntimeException（未检查）
6.5.3 处理异常
try { readTavernMenu() } catch (e: Exception) { println("出错了: ${e.message}") }

6.6先决条件函数

  • Kotlin 标准库的 checkNotNull / requireNotNull / error / require / check
  • 用一行代码在条件不满足时抛出异常
val name = requireNotNull(inputName) { "名字不能为空" }

6.7深入学习

  • Java 有已检查（checked）与未检查（unchecked）异常之分；Kotlin 只有未检查异常
  • 可空性如何保证：类型系统 + 编译期检查 + 显式可空声明
第 7 章

字符串

本章目标：掌握字符串截取、字符串操作、字符串比较

7.1字符串截取

7.1.1 substring
val str = "Madrigal" val sub = str.substring(0, 3) // "Mad"
7.1.2 split
val order = "wine,cheese,bread" val items = order.split(",") // [wine, cheese, bread]

7.2字符串操作

  • replace、toUpperCase、toLowerCase、trim 等
  • 不可变字符串：所有"修改"操作都返回新字符串，原串不变

第 9 章

标准库函数

本章目标：掌握 6 个常用标准库函数：apply、let、run、with、also、takeIf

这些函数都是接收者（receiver）上的扩展函数，可以极大简化代码。

9.1apply

val menuFile = File("menu.txt").apply { setReadable(true) setWritable(true) } // 返回对象本身
  • 上下文对象为 this（可省略），返回值是接收者本身
  • 用于对象配置：链式设置属性

9.2let

val name: String? = "Madrigal" val len = name?.let { println("长度: ${it.length}") }
  • 上下文对象为 it，返回值是 lambda 的结果
  • 常与 ?. 配合处理可空对象

9.3run

val result = "Madrigal".run { length } // 8
  • 结合了 let 和 apply：上下文是 this，返回 lambda 结果

9.4with

val result = with("Madrigal") { println("长度: $length") length // 最后一行作为返回值 }
  • 非扩展函数，需把接收者作为参数传入
  • 适用于对同一对象多次调用

9.5also

val file = File("/tmp/x").also { println("创建文件: ${it.name}") }
  • 上下文为 it，返回接收者本身
  • 类似 apply，但 lambda 中用 it 而非 this

9.6takeIf / takeUnless

val file = File("/tmp/x") val readable = file.takeIf { canRead() } // 可读时返回 file，否则 null val unreadable = file.takeUnless { canRead() }
  • takeIf：满足条件返回接收者，否则 null
  • takeUnless：不满足条件返回接收者

9.7对比速查

apply
上下文 this，返回接收者 → 初始化配置
let
上下文 it，返回 lambda 结果 → 空安全调用
run
上下文 this，返回 lambda 结果 → 转换
with
上下文 this，非扩展 → 多个调用
also
上下文 it，返回接收者 → 副作用
takeIf
满足条件返回接收者，否则 null

  • 主线程负责 UI，长时间操作会卡顿甚至 ANR
  • 网络、数据库等应在 IO 线程

22.5async / await

val deferred = GlobalScope.async { fetchCharacterData() } val character = deferred.await()
  • async 返回 Deferred<T>，可通过 await() 拿到结果

22.6launch vs async

launch
不返回结果，类似 fire-and-forget
async / await
返回 Deferred<T>，可通过 await 取结果

22.7挂起函数 suspend

suspend fun fetchCharacter(): Character { return withContext(Dispatchers.IO) { // 网络请求 } }
  • suspend 标记的函数可在协程中挂起而不阻塞线程
  • 可用 withContext(Dispatchers.IO) 切换调度器
