第Ⅰ部分 C++基础

打底篇：建立 C++ 的基本心智模型——类型系统、表达式、语句、函数与类。读完本篇应能独立写出结构清晰、可编译运行的小型 C++ 程序。

第1章 开始

全书的破冰章节：从一个最简 main() 出发，串起 iostream 库、控制流与第一个类（Sales_item），让读者跑通“写—编—跑”三件事。

本章要点速览

  • C++ 程序由头文件 + 源文件组成，main 函数是唯一被操作系统显式调用的入口。
  • cin / cout / cerr / clog 是 iostream 提供的 4 个标准 I/O 对象。
  • while、for、if 是控制流三剑客，类则是把数据与操作绑定的基本单位。

关键概念

main 函数返回类型iostream命名空间 stdSales_item 类控制流 while/for/if注释 // 与 /* */

常见陷阱

  • 忘记 return 语句（main 隐式返回 0，但仍建议显式写）
  • 中文标点出现在源码里
  • endl 与 "\n" 的混用导致刷新行为差异

第2章 变量和基本类型

C++ 是强类型语言：理解内置算术类型、变量声明、复合类型（引用 / 指针）、const 限定与自定义数据结构，是写对代码的前提。

本章要点速览

  • 类型决定了对象所占内存大小、能参与的运算和生命周期。
  • 引用是已存在对象的别名；指针本身是一个对象，保存另一个对象的地址。
  • const 把“只读”这一意图写在类型系统里；constexpr 要求编译期可知。

关键概念

基本内置类型类型转换字面值常量变量声明 / 定义引用指针constconstexpr类型别名autodecltypestruct头文件保护

常见陷阱

  • 未初始化的内置类型变量值未定义
  • 把 int* 与 int& 混用
  • 把 constexpr 当成 const 的同义词

第3章 字符串、向量和数组

进入标准库的第一个窗口：string、vector、迭代器、内置数组与多维数组。重点在“用库而非手写”，以及迭代器这把通用钥匙。

第4章 表达式

表达式是 C++ 的血肉：算术、逻辑、关系、赋值、递增、成员访问、条件、位、sizeof、逗号以及无处不在的类型转换。掌握优先级与求值顺序才能写出可预期的代码。

本章要点速览

  • 表达式由运算符与运算对象组成，每个表达式都有结果与值类别（左值 / 右值）。
  • 优先级决定结合方式，但同一表达式中多个修改的求值顺序在 C++17 前大多未指定。
  • C++ 提供了 4 种显式类型转换：static_cast、dynamic_cast、const_cast、reinterpret_cast。

关键概念

左值 / 右值优先级与结合律算术 / 逻辑 / 关系运算符赋值递增递减 ++/--成员访问 . / ->条件 ? :位运算 & | ^ ~ << >>sizeof逗号 ,显式转换

常见陷阱

  • i++ 与 ++i 在表达式中的差异
  • 未定义求值顺序导致的 bug
  • 溢出与隐式窄化

第7章 类

C++ 的核心抽象机制：把数据与操作捆绑，并可控制其可见性。本章打通封装、构造函数、友元、类作用域、可变数据成员、聚合类、字面值常量类与静态成员。

本章要点速览

  • class 默认 private，struct 默认 public，这是两者唯一的语言差异。
  • 构造函数初始化列表是真正“初始化”成员的地方，函数体里是赋值。
  • const 成员函数：把 *this 声明为指向常量的引用；mutable 可绕过。

关键概念

抽象数据类型构造函数拷贝 / 赋值 / 析构访问控制 public / private友元 friend返回 *this类类型名字查找初始化列表委托构造函数隐式类型转换 / explicit聚合类字面值常量类static 成员

常见陷阱

  • 构造函数忘记初始化成员
  • 在构造 / 析构中调用 virtual（虚机制未启用）
  • 声明与定义顺序不一致

  • RTTI 让程序能在运行时问“这个对象到底是什么”。
  • 位域、union、volatile 几乎只在与 C / 硬件打交道的代码里使用。
