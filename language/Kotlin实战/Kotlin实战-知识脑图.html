译者序

这本书是一本系统讲解Kotlin语言的实战指南，由JetBrains的两位核心开发者Dmitry Jemerov和Svetlana Isakova撰写。本书不仅介绍Kotlin的基础语法，更深入探讨类型系统、集合与函数式编程、高阶函数与Lambda、泛型与反射、DSL构建等高级主题。译者希望读者通过本书理解Kotlin的设计哲学——务实、简洁、安全、互操作。

序

Kotlin是JetBrains打造的现代编程语言，目标是让Java开发者能够写出更简洁、更安全、更具表现力的代码。Kotlin运行在JVM上，与Java完全互操作，现已广泛应用于服务器端、Android开发等领域。本书是Kotlin团队核心成员亲自撰写的权威指南。

前言

本书面向有Java或类似JVM语言经验的开发者。读者应熟悉面向对象编程的基本概念，了解Java的核心特性如类、接口、泛型、Lambda等。阅读本书后，你将能够熟练使用Kotlin进行日常开发，理解其设计哲学，并能在实际项目中应用Lambda、高阶函数、DSL等高级特性。

📚 第1部分 Kotlin简介

第1章Kotlin：定义和目的

本章介绍Kotlin的定位、目标平台、设计哲学和工具链，建立对Kotlin的整体认知。Kotlin是针对Java平台的新编程语言，简洁、安全、务实，专注于与Java代码的互操作性。

1.1 Kotlin初体验

通过一个完整的例子：Person数据类 + maxBy函数 + Elvis运算符，看Kotlin的简洁与安全。

代码示例：Person与maxBy

Person数据类
用 data class 一行声明一个包含name和age的实体类，age默认为null。
maxBy函数
查找集合中满足条件的最大元素，接收lambda参数。
Elvis运算符(?:)
age为null时返回零，让缺失值处理更优雅。
try.kotl.in
在线Playground，输入代码即可运行，是上手Kotlin的最快方式。
data class Person(val name: String, val age: Int? = null) val people = listOf(Person("Alice"), Person("Bob", 29)) val oldest = people.maxBy { it.age ?: 0 } println(oldest) // Person(name=Bob, age=29)

1.2 Kotlin的主要特征

深入Kotlin关键属性：目标平台广泛、静态类型+类型推导、函数式+面向对象、开源、IDE支持。

1.2.1 目标平台

服务器端
编写Web应用后端，Spring 5.0+原生支持。
Android
Google官方推荐语言，Android Studio 3.0+支持。
iOS
通过Intel Multi-OS Engine让Kotlin运行在iOS设备上。
桌面应用
Kotlin+TornadoFX+JavaFX可构建桌面应用。
JavaScript
可编译成JavaScript运行在浏览器中。

1.2.2 静态类型

静态类型优势
性能更好、方法调用快；可靠性高、编译期检查；可维护性；IDE支持重构。
类型推导
编译器从上下文自动推断变量类型，兼顾静态类型与简洁。
智能转换
编译器跟踪is检查，自动在后续代码中转换类型。
函数类型
Kotlin原生支持函数类型，让函数式编程更自然。

1.2.3 函数式与面向对象

头等函数
把函数当作值：保存、传参、返回。
不可变性
使用不可变对象，状态创建后不能变化。
无副作用
纯函数输入相同时产生同样结果，不修改外部状态。
多线程安全
不可变数据+纯函数天然避免竞争问题。
易测试
无副作用的函数可独立测试，无需复杂环境。

1.2.4 免费开源 + IDE支持

Apache 2许可
Kotlin完全开源，源码在GitHub公开。
IntelliJ IDEA
IDE对Kotlin提供完整的代码补全、重构和调试支持。
Android Studio
基于IntelliJ，Android开发的官方推荐IDE。

1.4 Kotlin的设计哲学

务实、简洁、安全、互操作是Kotlin的四大设计哲学。

核心理念

务实
Kotlin不是学术性语言，旨在解决真实工程问题。
简洁
减少样板代码，让代码表达意图而非实现细节。
安全
通过类型系统把运行时错误提前到编译期。
互操作性
与Java无缝互调，可逐步迁移到Kotlin。

第2章Kotlin基础

本章学习Kotlin的基本要素：函数、变量、类、属性、控制结构、智能转换和异常处理。这些是编写任何Kotlin程序的基础。

2.1 基本要素：函数和变量

函数和变量是组成每个Kotlin程序的基本要素。

2.1.1 Hello, world!

fun关键字
声明函数的关键字(fun有乐趣的双关)。
参数类型位置
类型写在参数名后面(冒号分隔)。
顶层函数
函数可定义在文件最外层，不需放在类中。
数组是类
Kotlin没有特殊数组语法，使用Array<T>。
println
Kotlin标准库对System.out.println的简洁包装。
省略分号
和许多现代语言一样，行尾分号可省略。
fun main(args: Array<String>) { println("Hello, world!") }

2.1.2 函数

表达式与语句
Kotlin中if是表达式有值，赋值是语句无值。
表达式函数体
单表达式函数可省略花括号和return。
代码块体
多语句函数必须用花括号并显式return。
类型推导
表达式体函数可省略返回类型，编译器自动推断。
Unit类型
无返回值时使用Unit（类似Java的void）。
// 表达式体 fun max(a: Int, b: Int) = if (a > b) a else b // 代码块体 fun max(a: Int, b: Int): Int { return if (a > b) a else b }

2.1.3 变量

val
不可变引用，对应Java的final变量，优先使用。
var
可变引用，对应Java普通变量，必要时使用。
val可条件初始化
val只能赋值一次，但可通过if在不同分支初始化。
val引用不可变但对象可变
val只保证引用不变，对象内容仍可修改。
优先使用val
默认使用val，必要时才换var，使代码更接近函数式风格。
val name = "Alice" // 不可变引用 var age = 29 // 可变引用 val result: String = if (true) "yes" else "no"

2.1.4 字符串模板

$变量
用$前缀在字符串中引用局部变量。
${表达式}
用${}在字符串中嵌入任意表达式。
$转义
需要显示美元符号时用\$转义。
嵌套双引号
在${}内可直接使用双引号。
val name = "Alice" println("Hello, $name!") // Hello, Alice! println("1 + 1 = ${1 + 1}") // 1 + 1 = 2

2.2 类和属性

面向对象基础：如何在Kotlin中声明类和属性。

2.2.1 属性

属性头等公民
Kotlin用val/var声明属性，自动生成getter/setter。
val只读
只生成getter，无setter。
var可写
生成getter和setter。
is前缀特例
